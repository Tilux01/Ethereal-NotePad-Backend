# Ethereal Notepad Backend

Backend service for the Ethereal notepad application.

## About

A Node.js server that stores and syncs notes for the Ethereal notepad apps.

## Features

- Note storage
- Sync APIs
- Simple REST design

## Tech Stack

- Node.js
- Express

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
